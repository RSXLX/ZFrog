# @zfrog/shared

V2-01 共享契约包。

## 内容

1. `src/types/*`：跨端 DTO 与事件类型。
2. `src/schemas/*`：zod 契约校验。
3. `src/__tests__/contract.shared.test.ts`：共享契约测试样例。

## 脚本

1. `npm run build --workspace @zfrog/shared`
2. `npm run type-check --workspace @zfrog/shared`
3. `npm run test:contract --workspace @zfrog/shared`
